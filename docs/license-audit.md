# License Boundary

CrowdTensor source is Apache-2.0 under `LICENSE` and `pyproject.toml`.

Model weights, datasets, plugins, container images, and hosted compute remain
separate works under their upstream terms. The wheel does not include model
weights, datasets, credentials, notebook files, or local Campaign state.

Every Campaign operator must pin and review model/data licenses, redistribution
rights, personal-data handling, and output ownership before accepting
contributors. An unknown dependency license is a review finding, not an
automatic relicensing decision.
